# Raygate

> **Неофициальный проект.** Raygate — независимо разрабатываемый шлюз для подписок, совместимых с Happ. Он **не является официальным продуктом Happ**, не связан с разработчиками или издателем Happ и не поддерживается ими. Название Happ упоминается исключительно для обозначения совместимости с форматом подписок.
